# Google Search Console — Bulk Inspector & Indexing

Userscript для Google Search Console, который помогает эффективно работать с большими списками URL и автоматизировать рутинные действия в интерфейсе Search Console.

С его помощью можно:

- быстро проверить, какие страницы уже индексированы;
- отфильтровать только неиндексированные URL;
- отправить запросы на переобход только для нужных страниц;
- обработать весь список без предварительной проверки;
- сохранить текущее состояние проекта и продолжить позже;
- экспортировать результаты в CSV для дальнейшего анализа.

## Что умеет скрипт

- загружать список URL, по одному на строку;
- проверять статус индексации через интерфейс Search Console;
- отправлять запросы на переобход страниц;
- работать в режиме проверки списка, только для неиндексированных или для всего списка;
- поддерживать паузу, остановку и продолжение очереди;
- сохранять и загружать проект;
- экспортировать статистику и результаты в CSV;
- отслеживать ограничения квоты Google и автоматически останавливать обработку при необходимости.

## Зачем это нужно

При работе с большим сайтом или набором страниц проверка индексации вручную в Search Console занимает много времени. Обычно это требует повторяющихся действий в интерфейсе: открытие URL, проверка статуса, принятие решения о повторной индексации, сбор результатов. Скрипт сокращает рутинные операции и помогает быстро обрабатывать большие списки без постоянного ручного вмешательства.

## Поддерживаемые менеджеры userscript

- Tampermonkey
- Violentmonkey
- Greasemonkey (если доступна совместимость с текущим браузером и сайтом)

## Установка

1. Откройте Google Search Console и выберите нужный ресурс.
2. Установите менеджер userscript в браузер.
3. Загрузите файл `google-search-console-bulk-inspector-indexing.user.js`.
4. Откройте страницу Search Console и активируйте скрипт через панель менеджера.
5. После запуска скрипт будет доступен в интерфейсе ресурса.

## Использование

1. Откройте нужный ресурс в Google Search Console.
2. Вставьте список URL в поле ввода, по одному URL на строку.
3. Нажмите `Добавить ссылки`.
4. Выберите один из режимов:
   - `Проверить список`;
   - `Отправить только неиндексированные`;
   - `Отправить весь список без проверки`.
5. При необходимости используйте кнопки:
   - `Пауза`;
   - `Стоп`;
   - `Сохранить проект`;
   - `Экспорт результатов`.
6. После завершения работы можно сохранить проект или выгрузить результаты в CSV для дальнейшей обработки.

## Важные замечания

- Скрипт работает только на страницах Google Search Console.
- Для корректной работы нужен активный ресурс в Search Console и доступ к интерфейсу Google.
- Скрипт не обходит ограничения Google и не меняет официальную логику сервиса.
- Google может менять интерфейс, лимиты и поведение квот, поэтому при обновлениях интерфейса возможны корректировки.
- Используйте скрипт ответственно и в рамках допустимых правил использования платформы.
